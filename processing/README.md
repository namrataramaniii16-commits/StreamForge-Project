# StreamForge

## Project Description
This project processes temperature data using a sliding window approach and calculates the rolling average.
  
## Features
- Maintains a fixed window size of 3
- Removes the oldest temperature automatically
- Calculates rolling average

## Project Structure

processing/
│── main.py
│── rolling_average.py
│── window_processing.py

## How to Run

Open terminal and run:

```bash
python processing/main.py
